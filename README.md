# 💍 mytaklif.uz — Zamonaviy Onlayn To'y Taklifnomalari Xizmati

## 📌 Loyiha Haqida va Nima Uchun Yaratilgan?

An'anaviy qog'oz taklifnomalar qimmat, chop etish va mehmonlarga yetkazib berish ko'p vaqt hamda mehnat talab qiladi. Qolaversa, qog'oz taklifnomada musiqa qo'yib bo'lmaydi, to'yxona manzilini xaritada ko'rsatish qiyin va qaysi mehmon kelishi yoki kelmasligini oldindan bilish imkonsiz.

**mytaklif.uz** ushbu muammolarni to'liq bartaraf etish uchun yaratildi:
* **Tejamkorlik va tezlik**: Bor-yo'g'i 3–5 daqiqada tayyorlanadi, narxi qog'oz taklifnomalardan bir necha barobar arzon (bir martalik 50 000 so'm).
* **Cheksiz ulashish**: Bitta havola orqali (`mytaklif.uz/t/kelin-va-kuyov`) Telegram, WhatsApp yoki SMS orqali istalgancha (100, 1000+) mehmonga yuborish mumkin.
* **Interaktiv tajriba**: Jonli milliy/romantik musiqa yangraydi, to'ygacha qolgan vaqt soniyalarda hisoblanadi, mehmonlar to'yxonaga bir bosishda yo'l (Google/Yandex Maps) ochadilar.
* **Onlayn RSVP nazorati**: Mehmonlar to'yga kelishini oldindan tasdiqlaydilar, bu esa to'y egalariga joylar va xarajatlarni aniq hisoblash imkonini beradi.

## 🗄 Supabase Ma'lumotlar Bazasini Sozlash

Loyiha Supabase bilan to'liq integratsiya qilingan. Ma'lumotlar bazasida jadvallarni yaratish uchun quyidagi qadamlarni bajaring:

1. [Supabase Dashboard](https://supabase.com/dashboard) ga kiring va loyihangizni oching (`pjozbyqllacpzqnxhptn`).
2. Chap menyudan **SQL Editor** bo'limiga o'ting.
3. Loyihadagi [`supabase_schema.sql`](file:///c:/Users/Zevs/Desktop/lesssons/taklifnoma/momento/supabase_schema.sql) faylining to'liq tarkibini nusxalab, SQL Editor oynasiga joylashtiring.
4. **"Run"** tugmasini bosing.
   * `invitations`, `rsvps`, `wishes`, `site_stats` jadvallari yaratiladi.
   * Row Level Security (RLS) xavfsizlik qoidalari yoqiladi.
   * Boshlang'ich namuna ma'lumotlar avtomatik yoziladi.

### `.env` Sozlamalari
Loyihaning ildiz papkasidagi `.env` faylida Supabase kalitlari sozlangan:
